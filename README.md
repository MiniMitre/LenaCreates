# LenaCreates.art

This is the code for the [LenaCreates.art website](https://lenacreates.art).

The site has separate pages at `/about/`, `/portfolio/`, `/shop/`, and
`/contact/`.

The shop uses product detail pages and a browser-persisted shopping basket.
Stripe setup and remaining checkout steps are documented in
[STRIPE_INTEGRATION_TODO.md](STRIPE_INTEGRATION_TODO.md).
